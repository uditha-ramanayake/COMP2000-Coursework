
# COMP2000 Coursework

## Overview
This repository contains my COMP2000 coursework experiments using PyTorch and the CIFAR-10 image classification dataset.

## Exercises
- Exercise 1: Multi-Layer Perceptron (MLP)
- Exercise 2: Convolutional Neural Network (CNN)
- Exercise 3: Regularisation
- Exercise 4: Network Width and Depth

## Technologies Used
- Python
- PyTorch
- Torchvision
- Matplotlib
- Jupyter Notebook

## Dataset
CIFAR-10 is used for image classification. The dataset is downloaded automatically through Torchvision and is not included in this repository.
